# DevPulse

DevPulse is a Laravel learning platform for discovering and exploring practical development workshops.

## Features

- Responsive Laravel Blade interface
- Reusable Blade components
- Dynamic workshop routes
- Workshop details pages
- About page with community statistics
- Contact page with support information
- Custom 404 page
- Responsive Tailwind CSS design

## Core Routes

| Route             | Description      |
| ----------------- | ---------------- |
| `/`               | Home page        |
| `/workshops`      | All workshops    |
| `/workshops/{id}` | Workshop details |
| `/about`          | About DevPulse   |
| `/contact`        | Contact page     |

## Technologies

- Laravel
- PHP
- Blade
- Tailwind CSS
